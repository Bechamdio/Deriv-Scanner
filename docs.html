Deriv Scanner Documentation

Version 1 - Real-time Market Analysis

Overview V1

Deriv Scanner is a real-time market analysis tool that connects to Deriv's WebSocket API to analyze volatility indices (10, 15, 25, 75, 100) and generate trading signals based on technical analysis.

⚠️ Important: Version 1 is a demo/analysis tool only. It does not execute trades. Trading features will be added in future versions after thorough testing.

Key Features (V1)

  • WebSocket connection to Deriv live market data
  • Support for Volatility 10, 15, 25, 75, 100 indices
  • Real-time price tick collection and analysis
  • Technical indicators: SMA, EMA, RSI, MACD, Volatility, Standard Deviation
  • Automated trading signal generation (BUY/SELL/WAIT)
  • Signal strength percentage (0-100%)
  • Live price tracking and movement analysis
  • Event logging and analysis details

Getting Started

Step 1: Open the Scanner

Open index.html in a modern web browser (Chrome, Firefox, Safari, or Edge).

Step 2: Select a Volatility Index

Use the dropdown menu to select one of the available indices:

Index Description Use Case
Volatility 10 Lowest volatility, 1-minute expiry Scalping, tight spreads
Volatility 15 Low volatility Short-term trades
Volatility 25 Moderate volatility Balanced trading
Volatility 75 High volatility Aggressive trading
Volatility 100 Highest volatility, 1-minute expiry Maximum movement

Step 3: Connect WebSocket

Click the "Connect WebSocket" button to establish a real-time connection to Deriv's market data stream.

Look for the green "Connected" status badge once the connection is established.

Step 4: Monitor the Scanner

Watch the real-time price updates, volatility calculations, and trading signals as they update live.

Technical Indicators

Simple Moving Average (SMA)

Average price over the last 20 ticks. Used to identify trend direction.

Exponential Moving Average (EMA)

Weighted moving average giving more weight to recent prices. More responsive than SMA.

Relative Strength Index (RSI)

Measures momentum on a scale of 0-100. Values below 30 suggest oversold conditions (potential BUY), values above 70 suggest overbought conditions (potential SELL).

MACD (Moving Average Convergence Divergence)

Compares 12-period EMA with 26-period EMA. Positive MACD indicates uptrend, negative indicates downtrend.

Volatility (Standard Deviation)

Measures how much prices deviate from the average. Higher values indicate more price movement.

Movement (Range)

Measured in pips, shows the difference between highest and lowest price in recent period.

Signal Generation

The scanner generates trading signals based on multiple technical indicators with a scoring system:

Scoring Algorithm

Condition Impact
RSI < 30 (Oversold) +15 points → BUY signal
RSI > 70 (Overbought) -15 points → SELL signal
Volatility > 5% +10 points
Strong Movement (>100 pips) +5 points
MACD Positive +10 points
MACD Negative -10 points

Signal Interpretation

  • BUY - Score > 65: Conditions favor uptrend
  • SELL - Score < 35: Conditions favor downtrend
  • WAIT - Score 35-65: Neutral or insufficient data

Signal Strength: Displayed as 0-100%, showing confidence level of the signal.

Data Collection

Tick Collection

The scanner collects individual price ticks (quotes) from the WebSocket stream. A "tick" is a single price update with timestamp. Each tick is added to the analysis buffer.

Analysis Window

Last 20 ticks are used for most calculations (SMA, volatility, movement, high/low). Longer periods (RSI uses 14, MACD uses 12/26) use their respective lookback windows.

Data Retention

Maximum of 100 recent ticks are retained in memory. Older ticks are automatically discarded.

JavaScript API

DerivWebSocket Class

Manages connection to Deriv API and tick stream.

deriv.connect() // Connect to WebSocket
deriv.disconnect() // Close connection
deriv.subscribe(index) // Subscribe to volatility index
deriv.getTicks() // Get array of collected ticks
deriv.getTickCount() // Get total ticks collected
deriv.resetTicks() // Clear tick collection
deriv.on(event, callback) // Register event listener

TechnicalAnalyzer Class

Performs technical analysis on price data.

analyzer.addPrice(price) // Add price to analysis
analyzer.analyze() // Get complete analysis object
analyzer.calculateSMA(period) // Get simple moving average
analyzer.calculateEMA(period) // Get exponential moving average
analyzer.calculateRSI(period) // Get RSI (0-100)
analyzer.calculateVolatility() // Get volatility %
analyzer.calculateMovement() // Get movement in pips
analyzer.clear() // Reset analyzer

SignalGenerator Class

Generates trading signals based on analysis.

signalGenerator.generateSignal() // Get signal object
signalGenerator.setThreshold(n) // Set custom threshold

Event Log

The scanner maintains a real-time event log showing:

  • Connection status changes
  • Subscription events
  • Signal generation with reasons
  • Errors and warnings
  • System messages

Each log entry includes timestamp and color-coded type (info, success, warning, error). Maximum 50 entries are displayed; older entries scroll off the bottom.

Troubleshooting

Connection Failed

If you see "Connection failed" errors, check that you have an active internet connection. Deriv's WebSocket server must be accessible. Try disconnecting and reconnecting.

No Ticks Received

Ensure you've selected a volatility index before connecting. Wait a few seconds after connecting for ticks to start arriving.

Signals Not Generating

The scanner needs at least 20 ticks before it starts analyzing. Wait for "Ticks Collected" counter to reach 20+. Then signals should appear on the next analysis cycle.

Browser Console Errors

Open your browser's developer console (F12 or Cmd+Option+I) to see detailed error messages. These can help diagnose connection or data issues.
